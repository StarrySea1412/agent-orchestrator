本片提要

10 月 31 日晚，DeepSeek Harness 团队开源了一份 Super-agent 原型：不是新模型，而是一套「AI 指挥 AI」的车站调度规程——长驻的 Router 只 routing 不干活，Worker 各自在隔离 session 里执行单一工单，没人叫就闭嘴。这篇把 15205 行真实代码和九篇编号设计文档摊开，逐层核对：授权怎么走门禁、工单怎么排班、为什么主 Session 连 sleep 都被禁止，以及一张文档自己承认「尚未实现」的边界清单。

READ THE DISCLAIMER · README 第一句（原文）

「Research prototype for reference only, not an official DeepSeek product. … much of the engineering done by coding agents.」——它自己先承认三件事：这是研究原型；部分文章里的设计是未来方向，原型里并未实现；连代码大部分都是编码 Agent 写的。

这份诚实反而让人愿意认真读它：它不是发布会 PPT，是一份可以逐行核对的调度规程。本篇的所有引文都核对到真实文件——九篇编号文档、11 个提示词文件、92 个源码文件，以及一张连「文档必须只向后链接」都有测试管着的规格清单。

Vol.10 给 Agent 配了一台总机，接的是模型：哪条线路活着，电话转给谁。这一篇要接的换成了Agent 本身：一个长驻的调度者接下所有来电，自己从不干活，把活写成一张张工单，派给一群互相看不见、也永远听不见彼此的执行者。DeepSeek 给它起名 Super-agent，而它的第一性原理朴素得近乎固执——尽量少占人的注意力，尽量多交付价值。全篇最动人的不是某个聪明算法，而是为这句话付出的所有纪律：一张三格准入表、一条 200 行红线、一个被禁止 sleep 的主 Session，和十二个「想清楚了但决定不要」的概念。
